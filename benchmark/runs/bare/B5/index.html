jfmt — make JSON legible, fast

A single-binary CLI that formats, validates and colorizes JSON straight from the pipe. No config file, no flags required, no excuses.

$npm install -g jfmt
$brew install jfmt
zsh — demo

Why jfmt

--pipe-native

Reads stdin, writes stdout. Bolt it onto any pipeline without changing a single upstream tool.

--errors-that-help

Bad JSON in, useful message out — line, column and a caret pointing at the offending byte.

--color

Syntax highlighting that respects NO_COLOR and degrades cleanly when output isn't a TTY.

--sort-keys

Deterministic output for diffs and golden tests. Stable ordering, always.

--check

Exit code 1 on malformed input. Ideal for pre-commit hooks and CI lint steps.

--0-config

No dotfile, no plugin system. One binary, sensible defaults, overridable when needed.

The flags you'll actually use

jfmtFormat stdin to stdout, 2-space indent, colors when the output is a terminal.
--indent 4 | tabChoose your indentation. TABs are fine here, we don't judge.
--compactOne line, no spaces — for logs and wire formats.
--sort-keysRecursively sort object keys for stable diffs.
--checkValidate only. Exit 0 if clean, 1 with a precise error position if not.
--no-colorForce plain output. Also honored via NO_COLOR=1.
--versionPrint the version and exit. It's fast too.
