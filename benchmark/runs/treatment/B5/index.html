“gofmt, but for JSON.”

JSON formatting for people who live in the terminal.

jfmt formats JSON the same way every time: byte-stable output, keys sorted only when you ask, one precise diagnostic when the input is broken. It reads stdin, writes stdout, and stays out of your pipe.

Why another formatter

    

      

        
deterministicsame bytes, every run

        
Formatting is stable across versions and platforms: the output of today is byte-identical to the output of a year ago. Files stop churning in diffs, so code review sees your change, not the formatter's mood.

      

      

        
fastsingle pass, streaming

        
One pass, no tree re-walk, no pretty-print regressions on large files. A 10 MB log dump formats before your terminal repaints. Numbers below; rerun them yourself with jfmt --bench.

      

      

        
pipeablestdin to stdout, exit codes that mean something

        
curl … | jfmt | jq .items just works. Exit 0 on success, 1 on parse errors, 2 on usage errors, so set -e scripts behave. Diagnostics print the line and column, not a byte offset alone.
